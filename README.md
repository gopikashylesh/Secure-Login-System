# Secure Login System

## Overview
A secure web application developed using Flask that allows users to register, log in, and access a protected dashboard securely.

## Features
- User Registration
- Secure Login
- Password Hashing using bcrypt
- SQLite Database
- Session Management
- Logout
- Responsive User Interface

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- Flask-Bcrypt
- SQLite
- HTML
- CSS

## Installation

```bash
pip install -r requirements.txt
python app.py
```
